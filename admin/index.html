Content Control — Publish / Hide

Tabel di bawah menampilkan status Materi dan Praktik untuk seluruh 16 minggu. Klik Toggle untuk preview instan Publish ⇄ Hide pada browser ini.

Cara permanen (direkomendasikan): buka assets/js/course-config.js, cari minggu yang ingin diubah, lalu ubah material: false / practice: false menjadi true (atau sebaliknya untuk menyembunyikan kembali), lalu simpan & commit. Perubahan pada file ini berlaku untuk semua pengunjung setelah di-deploy.

Tombol Toggle di bawah hanya membuat preview override pada browser ini saja (localStorage) — cocok untuk mendemokan tampilan Publish/Hide dengan cepat, tapi tidak mengubah file dan tidak terlihat oleh mahasiswa lain.

Catatan Keamanan: Panel ini adalah demonstrasi alur admin untuk static website (GitHub Pages) dan tidak memiliki autentikasi sungguhan. Status publikasi permanen disimpan di course-config.js (bagian dari kode sumber, publik jika repo publik); preview override tersimpan di localStorage browser ini dan dapat diubah siapa pun lewat devtools. Untuk kontrol akses yang sesungguhnya, integrasikan Firebase Authentication + Firestore atau Supabase Auth + Database sebagai backend admin.
