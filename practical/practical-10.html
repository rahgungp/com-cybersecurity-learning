PRACTICAL LAB · MINGGU 10

Endpoint & Malware Security

🧪 Malware / IOC Analysis

⏱ 45–60 menitReferensi Output: Malware / IOC Analysis

Objective

Mahasiswa mampu menganalisis Indicator of Compromise menggunakan data publik yang aman, tanpa menangani sampel malware aktif.

Scenario

Mahasiswa diberikan daftar contoh IOC (file hash, nama file, domain, dan timestamp) berdasarkan metadata publik yang aman — bukan sampel malware aktif yang sesungguhnya.

Tools

  • VirusTotal (pencarian hash/domain publik)
  • Worksheet IOC (disediakan)

Environment

Hanya menggunakan metadata publik yang aman (hash, nama file, domain). DILARANG mengunduh atau mendistribusikan sampel malware aktif dalam bentuk apa pun.

Instructions

  1. Untuk setiap IOC pada daftar, catat jenisnya (hash/domain/IP/URL).
  2. Cari hash atau domain tersebut menggunakan VirusTotal (gunakan hanya data contoh/publik yang diberikan).
  3. Catat hasil deteksi (berapa vendor yang menandainya berbahaya, jenis malware yang teridentifikasi jika ada).
  4. Klasifikasikan tingkat keyakinan (confidence) bahwa IOC tersebut memang berbahaya.
  5. Usulkan langkah containment dan response jika IOC ini ditemukan pada endpoint organisasi.

Expected Output

Tabel analisis IOC berisi: jenis IOC, hasil pencarian, tingkat keyakinan, dan rekomendasi containment/response.

Analysis

  • Mengapa satu hasil deteksi saja dari satu vendor belum cukup untuk memastikan sebuah file berbahaya?
  • Bagaimana IOC membantu mempercepat deteksi dibanding menganalisis setiap file dari awal?

Questions

  1. Apa perbedaan antara worm dan trojan dalam cara penyebarannya?
  2. Mengapa praktik ini tidak boleh menggunakan sampel malware aktif secara langsung?

Assignment

Susun Malware/IOC Analysis Report singkat berdasarkan hasil pemeriksaan IOC yang diberikan.
