PRACTICAL LAB · MINGGU 04

Authentication & Access Control

🧪 Access Control Analysis

⏱ 45–60 menitReferensi Output: Access-Control Analysis

Objective

Mahasiswa mampu menganalisis mekanisme authentication dan authorization pada sebuah sistem serta mengevaluasi kesesuaiannya dengan prinsip least privilege.

Scenario

Sebuah aplikasi manajemen tugas kampus memiliki tiga jenis pengguna: Mahasiswa, Dosen, dan Admin Akademik. Saat ini seluruh pengguna login dengan password saja, dan seluruh dosen memiliki akses yang sama seperti admin akademik.

Tools

  • Worksheet access-control (disediakan)

Environment

Analisis berbasis skenario tertulis, tidak memerlukan akses sistem nyata.

Instructions

  1. Identifikasi siapa saja user dan apa role masing-masing.
  2. Identifikasi resource yang perlu dilindungi (misal: nilai, jadwal, data pribadi).
  3. Tentukan permission yang seharusnya dimiliki tiap role berdasarkan least privilege.
  4. Evaluasi mekanisme authentication saat ini dan usulkan perbaikan (misal MFA).
  5. Evaluasi mekanisme authorization saat ini dan usulkan perbaikan (misal RBAC).

Expected Output

Tabel role-permission (RBAC matrix sederhana) dan rekomendasi perbaikan authentication & authorization.

Analysis

  • Risiko apa yang muncul karena dosen memiliki akses setara admin akademik?
  • Apakah MFA perlu diterapkan untuk semua role, atau cukup role tertentu? Jelaskan.

Questions

  1. Berikan satu contoh authorization yang salah meskipun authentication berhasil.
  2. Apa risiko keamanan jika least privilege tidak diterapkan pada sistem ini?

Assignment

Susun Access-Control Analysis Report berisi RBAC matrix dan rekomendasi authentication/authorization.
