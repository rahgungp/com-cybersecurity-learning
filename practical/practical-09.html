PRACTICAL LAB · MINGGU 09

Web & Application Security

🧪 Web Vulnerability Analysis

⏱ 45–60 menitReferensi Output: Web Vulnerability Analysis

Objective

Mahasiswa mampu menginspeksi HTTP request/response sederhana dan mengidentifikasi potensi kerentanan secara defensif pada aplikasi web yang sengaja dibuat rentan untuk latihan (intentionally vulnerable application) di lingkungan lokal.

Scenario

Mahasiswa menggunakan aplikasi web latihan yang sengaja dibuat rentan (contoh: OWASP Juice Shop atau DVWA) yang dijalankan secara lokal di komputer sendiri, bukan sistem publik siapa pun.

Tools

  • Browser Developer Tools (Network tab)
  • Aplikasi latihan rentan yang dijalankan secara lokal (mis. OWASP Juice Shop / DVWA)

Environment

WAJIB dijalankan pada local lab / simulated environment milik sendiri. Dilarang keras menargetkan website publik, sistem organisasi nyata, atau akun orang lain.

Instructions

  1. Jalankan aplikasi latihan rentan secara lokal sesuai panduan instalasinya.
  2. Gunakan Developer Tools untuk mengamati satu HTTP request dan response saat login/mengisi formulir.
  3. Identifikasi parameter input apa saja yang dikirim ke server.
  4. Analisis apakah ada input yang tampak tidak divalidasi (misal diterima format bebas tanpa batasan).
  5. Petakan temuan ke kategori OWASP Top 10:2025 yang paling relevan.
  6. Rekomendasikan mitigasi untuk setiap temuan.

Expected Output

Laporan temuan berisi: parameter yang dianalisis, potensi kerentanan, kategori OWASP terkait, dan rekomendasi mitigasi — tanpa bukti eksploitasi aktif terhadap sistem pihak lain.

Analysis

  • Mengapa validasi input sebaiknya dilakukan di sisi server, bukan hanya di sisi client (browser)?
  • Apa risiko jika pesan error aplikasi menampilkan detail teknis internal secara berlebihan?

Questions

  1. Sebutkan satu kategori OWASP Top 10:2025 dan jelaskan secara umum apa yang dicakupnya.
  2. Mengapa praktik ini harus dilakukan pada aplikasi lokal, bukan situs publik?

Assignment

Susun Web Vulnerability Analysis Report singkat berdasarkan aplikasi latihan lokal yang digunakan.
