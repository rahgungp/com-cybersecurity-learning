MODULE 10 · MINGGU KE-10

Endpoint & Malware Security

VirusTotal Output: Malware / IOC Analysis

🎯 Learning Objectives

Setelah menyelesaikan materi ini, mahasiswa mampu:

  • Menjelaskan jenis-jenis malware: trojan, worm, ransomware, spyware.
  • Menjelaskan konsep persistence dan endpoint protection.
  • Menjelaskan konsep Indicator of Compromise (IOC).
  • Menganalisis IOC sederhana menggunakan sumber data publik yang aman.

📖 THEORY

Jenis Malware

Trojan menyamar sebagai program sah untuk menipu pengguna agar menjalankannya. Worm menyebar sendiri antar sistem tanpa perlu interaksi pengguna. Ransomware mengenkripsi data korban dan meminta tebusan untuk kunci dekripsinya. Spyware diam-diam memantau aktivitas pengguna, misalnya merekam ketikan (keylogger) atau mencuri kredensial.

Persistence & Endpoint Protection

Persistence adalah teknik yang digunakan malware agar tetap aktif meskipun perangkat di-restart, misalnya dengan menanamkan diri pada startup process. Endpoint protection adalah kumpulan kontrol keamanan pada perangkat individu (laptop, server) seperti antivirus modern (EDR — Endpoint Detection and Response) yang mendeteksi perilaku mencurigakan, bukan hanya signature file yang dikenal.

Indicator of Compromise (IOC)

IOC adalah artefak yang mengindikasikan kemungkinan kompromi sistem — dapat berupa file hash, nama file mencurigakan, alamat IP, domain, atau URL yang terkait aktivitas berbahaya. IOC dikumpulkan dari analisis insiden sebelumnya dan dibagikan antar organisasi untuk mempercepat deteksi ancaman serupa.

Example

Sebuah organisasi menerima daftar IOC dari komunitas keamanan berupa beberapa file hash dan domain yang diketahui terkait kampanye ransomware tertentu. Tim keamanan memeriksa log endpoint protection mereka dan mencocokkan hash tersebut untuk memastikan tidak ada perangkat yang pernah menjalankan file berbahaya itu.

Case Study

Seorang karyawan melaporkan laptopnya berjalan lambat dan muncul pop-up asing. Tim IT memeriksa proses yang berjalan dan menemukan file mencurigakan, lalu menghitung hash file tersebut dan memeriksanya pada VirusTotal — hasil pemeriksaan menunjukkan file tersebut terdeteksi sebagai trojan oleh beberapa vendor antivirus, sehingga laptop segera diisolasi dari jaringan (containment) sebelum dilakukan pembersihan.

Key Takeaways

  • Setiap jenis malware memiliki cara kerja dan tujuan yang berbeda-beda.
  • Persistence memungkinkan malware bertahan meski perangkat di-restart.
  • IOC (hash, IP, domain, URL) membantu mendeteksi ancaman yang sudah dikenal secara cepat.
  • Endpoint protection modern berfokus pada deteksi perilaku, bukan hanya signature.
