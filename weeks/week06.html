MODULE 06 · MINGGU KE-06

Network Security Fundamentals

WiresharkFirewall Output: Packet Analysis

🎯 Learning Objectives

Setelah menyelesaikan materi ini, mahasiswa mampu:

  • Menjelaskan dasar TCP/IP, port, DNS, dan HTTP/HTTPS dari sudut pandang keamanan.
  • Menjelaskan fungsi firewall, IDS, IPS, VPN, dan network segmentation.
  • Membaca dan menganalisis paket jaringan sederhana.
  • Mengidentifikasi aktivitas mencurigakan pada traffic jaringan.

📖 THEORY

TCP/IP, Port, dan DNS

TCP/IP adalah kumpulan protokol dasar komunikasi internet. Port mengidentifikasi layanan spesifik pada sebuah host (misal port 443 untuk HTTPS). DNS menerjemahkan nama domain menjadi alamat IP — dari sisi keamanan, DNS juga rentan disalahgunakan (misal DNS spoofing) sehingga perlu perlindungan seperti DNSSEC.

HTTP/HTTPS

HTTP mengirim data dalam bentuk teks biasa yang rentan disadap, sedangkan HTTPS membungkus HTTP dengan TLS sehingga data terenkripsi selama transit. Praktik keamanan modern mewajibkan penggunaan HTTPS untuk seluruh layanan yang menangani data sensitif.

Firewall, IDS, IPS

Firewall menyaring traffic jaringan berdasarkan aturan (misal alamat IP, port). Intrusion Detection System (IDS) memantau traffic dan memberi peringatan saat mendeteksi pola mencurigakan, tanpa memblokirnya. Intrusion Prevention System (IPS) melangkah lebih jauh dengan secara aktif memblokir traffic yang terdeteksi berbahaya.

VPN & Network Segmentation

VPN (Virtual Private Network) membuat terowongan terenkripsi antara dua titik jaringan, sering digunakan untuk akses remote yang aman. Network segmentation membagi jaringan menjadi zona-zona terpisah sehingga jika satu segmen dikompromikan, penyerang tidak otomatis mendapat akses ke seluruh jaringan.

Example

Sebuah kantor menempatkan seluruh printer dan perangkat IoT pada VLAN terpisah dari komputer kerja staf (network segmentation), sehingga jika salah satu printer dikompromikan melalui vulnerability firmware, penyerang tidak dapat langsung menjangkau data di komputer staf.

Case Study

Tim keamanan sebuah kampus memeriksa log firewall dan menemukan ratusan percobaan koneksi ke port 3389 (Remote Desktop Protocol) dari berbagai alamat IP luar negeri dalam waktu singkat — pola ini konsisten dengan aktivitas port scanning otomatis yang mencari layanan remote desktop yang terekspos ke internet, dan langsung memicu tim untuk menutup akses RDP dari luar jaringan kampus.

Key Takeaways

  • Firewall menyaring, IDS mendeteksi dan memberi peringatan, IPS mendeteksi sekaligus memblokir.
  • HTTPS melindungi data in transit melalui TLS; HTTP polos rentan disadap.
  • Network segmentation membatasi dampak jika satu segmen jaringan dikompromikan.
  • Analisis paket membantu mengenali pola traffic normal vs mencurigakan.
