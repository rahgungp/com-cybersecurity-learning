MODULE 01 · MINGGU KE-01

Introduction to Cybersecurity

CIA TriadNIST Cybersecurity Framework (NIST CSF) 2.0 Output: Security Asset Identification

🎯 Learning Objectives

Setelah menyelesaikan materi ini, mahasiswa mampu:

  • Menjelaskan apa itu cybersecurity dan bedanya dengan information security.
  • Menjelaskan security landscape dan mengapa ancaman siber terus berkembang.
  • Menjelaskan security objectives melalui CIA Triad.
  • Mengidentifikasi aset informasi pada sebuah organisasi.

📖 THEORY

Apa itu Cybersecurity?

Cybersecurity adalah praktik melindungi sistem, jaringan, aplikasi, dan data dari akses, perubahan, atau perusakan yang tidak sah. Cakupannya lebih luas dari sekadar melindungi dokumen atau file — cybersecurity juga melindungi infrastruktur digital seperti server, perangkat jaringan, dan layanan cloud yang menjadi tempat data tersebut mengalir dan diproses.

Cybersecurity vs Information Security

Information security (InfoSec) adalah disiplin yang lebih luas, mencakup keamanan informasi dalam bentuk apa pun — digital maupun fisik (misalnya dokumen kertas terkunci di lemari arsip). Cybersecurity adalah subset dari information security yang berfokus khusus pada ancaman terhadap sistem digital dan dunia siber.

Security Landscape

Security landscape menggambarkan kondisi ancaman siber yang terus berubah: jenis serangan baru, teknik penyerang yang makin canggih, serta permukaan serangan (attack surface) yang meluas seiring adopsi cloud, perangkat mobile, dan IoT. Memahami landscape ini membantu organisasi memprioritaskan pertahanan sesuai risiko yang benar-benar relevan.

Security Objectives & CIA Triad

Tiga tujuan utama keamanan informasi dikenal sebagai CIA Triad: Confidentiality (kerahasiaan) memastikan data hanya diakses pihak berwenang; Integrity (integritas) memastikan data tidak diubah tanpa izin dan tetap akurat; Availability (ketersediaan) memastikan sistem dan data dapat diakses saat dibutuhkan. Hampir semua kontrol keamanan dapat dipetakan ke salah satu — atau kombinasi — dari ketiga tujuan ini.

Security Asset

Aset keamanan (security asset) adalah segala sesuatu yang bernilai bagi organisasi dan perlu dilindungi: data, perangkat keras, perangkat lunak, kredensial, reputasi, hingga sumber daya manusia. Langkah pertama dalam membangun program keamanan yang efektif adalah mengidentifikasi dan menilai aset-aset ini.

Example

Sebuah kampus memiliki aset berupa server akademik (menyimpan data mahasiswa), laptop dosen, dan akun email institusi. Server akademik memiliki nilai confidentiality dan integrity tinggi karena berisi data pribadi dan nilai; email institusi memiliki nilai availability tinggi karena dipakai untuk komunikasi harian.

Case Study

Sebuah startup e-commerce baru menyadari mereka belum pernah mendaftar aset digital mereka secara formal — mereka tidak tahu persis berapa banyak server, API key, dan akun cloud yang aktif. Ketika terjadi insiden kecil pada satu server yang lupa dinonaktifkan, tim baru sadar bahwa tanpa inventaris aset, mereka tidak bisa menilai risiko maupun merespons insiden secara cepat.

Key Takeaways

  • Cybersecurity adalah bagian dari information security yang berfokus pada ancaman digital.
  • CIA Triad (Confidentiality, Integrity, Availability) menjadi tujuan dasar semua kontrol keamanan.
  • Security landscape terus berubah — pertahanan harus disesuaikan secara berkala.
  • Identifikasi aset adalah langkah pertama sebelum menilai risiko dan merancang kontrol.
